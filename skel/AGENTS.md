# AGENTS.md

Rules and guidelines to follow when working on technical projects with me.

This document is split into multiple parts, so each section can be read only when its subject matter becomes relevant during work. Do not read them until that time, but at that time, they become mandatory reading.

When referencing clauses, here is the format: `<basename>#<section>[.subsection][.index]`. `<basename>` is the basename of the file in which the clause was found, e.g. `TESTS` for `TESTS.md`. `<section>` refers to the h2 markdown header `##` exactly at, or immediately preceding, the referenced line. Optional `[.subsection]`s if there is a deeper hierarchy of markdown headers, and `.index` (numeric, 1-indexed) if the referenced item is in an ordered or unordered list. Do not use line numbers in references.

All files below are located in one folder, `~/.config/agents/`, so the filename alone is used.

## Sections

### [Testing](TESTING.md)
Read before and while writing, auditing, reviewing, or debugging tests, including unit tests, functional tests, integration tests, end-to-end tests, and test helper code such as mocks, fixtures, and runners.

### [UI and UX](UIUX.md)
Read before and while coding, auditing, reviewing, or debugging UI, including web and mobile UI, TUIs, and CLIs, all of which count as UI.

### [Prose](PROSE.md)
Read before and while writing prose text, including explanatory documentation, block comments, introductions, guides, instructions, reports, issues, and pull requests.
